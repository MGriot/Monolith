Chapter 11

Troubleshooting & security

What protects the data, what to check first when something is off, and how to keep a copy of everything.

Model

Security model

AreaProtection
Accountsbcrypt hashes; no default accounts; sign-up off by default and approved by an administrator; login throttling; temporary passwords must be changed.
TokensLogin JWTs signed with SECRET_KEY; reset and verification tokens are single-purpose and refused as login tokens; reset links die when the password changes.
AuthorizationOne layer (app/api/access.py) for REST, websockets and MCP; roles read on every request; an endpoint matrix test fails when a route lacks a guard.
MCPPersonal tokens stored as SHA-256, optional expiry, revocable, re-checked per call; DNS-rebinding protection on the Host header.
UploadsRandom names, size limit, executable types refused, nosniff, SVG forced to download with a sandbox CSP; sketch previews are validated PNGs or server-rendered SVG with escaped text.
OutboundWebhooks refuse private and metadata addresses at save and send time, no redirects.
NetworkOnly the proxy is published; database and mail server are internal; rootless containers, non-root backend user.
Fixes

Common problems

SymptomCause and fix
Cannot sign in with admin@admin.comThere are no default accounts. Use FIRST_SUPERUSER_EMAIL; if it was never created, set both FIRST_SUPERUSER_* values and restart the backend.
Login answers 429Too many failed attempts for that account or address; wait LOGIN_WINDOW_SECONDS.
“E-mail is disabled” when approving a userApproval mails a temporary password; enable mail (EMAIL_ENABLED=true) or create the account through the API.
Mails stay pending, log shows 535 authentication failedThe mailbox password differs from SMTP_PASSWORD; re-run scripts/mail-bootstrap.sh.
Mail container restarts after two minutesNo mailbox exists; run scripts/mail-bootstrap.sh before the first start.
MCP client gets 401Missing, mistyped, revoked or expired token, or a deactivated account. Check Settings › MCP access: Last used stays empty when the token never reached the server.
MCP client gets 400 or 421The Host header is not allowed; add the name to MCP_ALLOWED_HOSTS.
MCP tool returns Permission deniedThe token owner lacks the role in that project; an admin changes it in Project Settings.
Sketch shows OfflineThe websocket cannot connect: check that the proxy forwards upgrades for /api/ (the bundled nginx does) and that your session has not expired (sign in again).
Others do not see my sketch editsNew sketches go live after the first Create. Viewers cannot draw. Several backend workers or replicas split rooms; run one.
Sketch thumbnail is an iconThe sketch was never saved with content, or its preview file was removed; open and save it once.
Webhook test fails with 400The URL resolves to a private address; set WEBHOOK_ALLOW_PRIVATE=true for self-hosted chat.
“Users need a normal e-mail domain”Special-use domains such as .local are refused in user addresses (1.3).

Data

Backup and restore

Two things hold state: the database and the uploads volume (files and sketch previews).

# back up
podman exec monolith_db sh -c 'pg_dump -U "$POSTGRES_USER" -Fc "$POSTGRES_DB"' > monolith.dump
podman run --rm -v monolith_uploads:/data -v "$PWD":/backup docker.io/library/alpine tar czf /backup/uploads.tgz -C /data .

# restore into a stopped backend
podman exec -i monolith_db sh -c 'pg_restore -U "$POSTGRES_USER" -d "$POSTGRES_DB" --clean --if-exists' < monolith.dump
podman run --rm -v monolith_uploads:/data -v "$PWD":/backup docker.io/library/alpine tar xzf /backup/uploads.tgz -C /data
Careful

Keep SECRET_KEY with the backup: without it every session and pending reset link is invalid (people simply sign in again). MCP tokens survive, since only their hashes are stored.
